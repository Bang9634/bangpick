# 서비스 간 계약

프론트·백엔드·Worker가 공유하는 API와 작업·결과 형식을 관리합니다. 기능 API와 작업 계약은 아직 정의하지 않았습니다.

현재 백엔드 초기 상태 확인 경로는 `/api/actuator/health`이며 전체 상태만 제공합니다. DB 연결까지 확인합니다. `/api/actuator/health/liveness`는 프로세스 생존 확인 경로입니다. Worker는 아직 이 API를 호출하거나 작업을 가져오지 않습니다.

향후 계약을 추가할 때 요청·응답·오류·인증·호환성을 함께 정의합니다. 비밀키·서명된 접근 URL의 실제 값·개인 PC 경로·원본 데이터를 예시에 넣지 않습니다.
