# 프로그램 흐름 시연

`demo/property-tour` 브랜치의 임시 프론트엔드 데모입니다. 실제 프로젝트의 API·DB·업로드·학습·스토리지·지도 공급자 선정과 연결하지 않습니다. 별도 백엔드 없이 지도 → 매물 선택 → 예시 정보 → PLY 방 둘러보기 흐름만 시연합니다.

## 실행

프론트 디렉토리에서 실행합니다.

```sh
npm ci
npm run dev
```

브라우저에서 `http://localhost:5173`을 엽니다. 지도는 Leaflet 1.9.4와 OpenStreetMap 타일을 사용하므로 인터넷이 필요하며 별도 API 키는 필요하지 않습니다. 지도 로딩이 실패해도 매물 목록으로 선택할 수 있습니다. 모든 매물은 가상이며 같은 방 모델을 엽니다.

## 모델 준비

3D Gaussian Splatting 결과 파일을 `frontend/public/demo/room.ply`에 직접 넣습니다. 업로드 UI나 서버 전송은 없습니다. 이 경로는 Git에서 제외됩니다. 모델은 로컬 웹 서버가 제공하며 외부 모델 서비스로 전송하지 않습니다. 파일을 넣은 뒤 뷰어의 다시 불러오기 버튼을 누르면 됩니다.

파일 확장자가 PLY여도 일반 메시·점군과 3DGS 데이터는 다릅니다. 가우시안의 위치·스케일·회전·불투명도·색상 등이 포함된 3DGS PLY가 필요합니다. 실제 파일 호환성과 용량에 따른 브라우저 성능은 해당 모델로 확인해야 합니다. 파일이 없는 상태를 방이 준비된 것처럼 표시하지 않습니다.

매물 정보와 모델 설정은 [data.ts](data.ts)에 있습니다. 다른 파일명을 쓰려면 `demoModel.url`을 변경합니다. 모델의 위아래가 뒤집히면 뷰어의 위아래 반전을 사용하거나 `rotation`을 수정합니다. 초기 카메라는 모델 경계의 중심에 놓이며, 바깥쪽 잡음이 많거나 원하는 시작 위치가 있으면 `initialPosition`과 `initialTarget`을 모델 회전 적용 후 좌표로 지정합니다. `moveSpeed`도 모델 스케일에 맞게 조정할 수 있습니다. 자동 카메라 위치가 촬영 범위 안임을 보장하지는 않습니다.

## 조작

- 캔버스를 누른 뒤 WASD로 수평 이동, Q/E로 높이 조절, Shift로 빠르게 이동합니다.
- 왼쪽 버튼 드래그로 시선을 바꾸고 휠로 앞뒤 이동합니다. 터치는 드래그 시선 변경을 지원합니다.
- R 또는 처음 위치 버튼으로 시작점에 돌아갑니다. Esc 또는 닫기로 매물 정보에 돌아갑니다.

WebGL2와 브라우저 하드웨어 가속이 필요합니다. 자유 탐색만 제공하며 벽 충돌·실내 이동 제한·모델 정리는 포함하지 않습니다. 미촬영 영역으로 이동하면 원본 모델의 뭉개짐이 나타날 수 있습니다. 모바일의 키보드 이동 UI는 추가하지 않았으며 시연은 PC를 기준으로 합니다.

## 제거

이 데모를 본 서비스로 병합할 필요는 없습니다. 변경을 직접 커밋하거나 stash로 보관한 뒤 main으로 전환하면 데모 구현과 본 작업을 구분할 수 있습니다. 커밋되지 않은 변경은 브랜치 전환 시 함께 따라갈 수 있으므로 먼저 Git 상태를 확인합니다. 코드를 옮긴 경우에는 `src/demo/`, `public/demo/`를 제거하고 `src/App.tsx`를 원래 소개 화면으로 되돌린 뒤 데모 전용 의존성인 `leaflet`, `three`, `@sparkjsdev/spark`, `@types/leaflet`, `@types/three`를 정리합니다. 다른 작업의 의존성을 함께 제거하지 않습니다.

공식 참고: [Leaflet](https://leafletjs.com/), [Spark SplatMesh](https://sparkjs.dev/docs/splat-mesh/), [OpenStreetMap 타일 정책](https://operations.osmfoundation.org/policies/tiles/). 지도 출처 표시는 유지합니다.
