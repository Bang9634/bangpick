# 프로젝트 정의

**bangpick**은 3D Gaussian Splatting 기반 실내 공간 재구성과 실측 정보 연동을 다루는 학부 캡스톤디자인 프로젝트입니다.

## 서비스 요구사항

- 등록자는 매물 정보와 직접 촬영하거나 이용에 동의받은 영상·사진을 등록하고, 재구성 결과를 검토한 뒤 공개합니다.
- 방문자는 지도에서 매물을 찾고 상세 화면에서 방을 둘러봅니다. 웹 투어는 WASD·마우스 조작과 품질을 확인한 영역 안에서의 이동을 지원합니다.
- 실측값과 평면도는 시각적 장면과 구분해 제시합니다. 원본 영상은 [보관·삭제 정책](decisions/0004-source-video-retention.md)을 따릅니다.

## 캡스톤 범위

| 구분 | 범위 |
| --- | --- |
| 1학기 | 매물 플랫폼, 사진·영상 처리, 3D 재구성, 비동기 작업, 웹 투어 |
| 2학기 | 실측값·평면도 연동, 좌표 정렬과 스케일 보정, 독립 측정과 비교, 불일치·미검증 항목 표시, 성능 개선 |
| 범위 밖 | 계약·결제, 전국 매물 자동 연동, 자동 가구 배치, 완전 자동 평면도와 모든 치수 복원, 이미지 조작 판정 |

## 핵심 용어와 제약

| 용어 | 의미 |
| --- | --- |
| 시각 모델 | 가우시안으로 표현한 장면. 시각적 품질이 구조·치수의 정확성을 보증하지 않음 |
| 충돌 데이터 | 뷰어에서 벽이나 가구 통과를 제한하는 별도 기하·복셀 데이터 |
| 이동 가능 영역 | 촬영 범위와 재구성 품질을 고려해 탐색을 허용하는 공간 |
| 실측 정보 | 외부 기준으로 측정한 값. 스케일 보정용과 독립 평가용을 구분 |
| 재구성 작업 | 입력 전처리·카메라 추정·학습·내보내기를 추적하는 처리 단위 |

미촬영 영역, 부분 재구성, 검증 불가 결과는 확인된 공간과 구분합니다. 구성 요소의 책임은 [시스템 설계](architecture.md), 구현 범위는 [개발 안내](development.md), 재구성 증거는 [실험 기록](experiments/README.md)에 있습니다.
