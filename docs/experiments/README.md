새 실험은 [템플릿](template.md)을 복사해 고유 번호와 이름을 붙입니다. 결과가 실패해도 입력·환경·명령·로그가 남으면 유효한 기록입니다.

원본 영상과 모델은 Git에 직접 넣지 않습니다. 접근 가능한 저장 위치·데이터 식별자·가능하면 파일 해시를 적고, 접근 권한이나 공간 촬영 동의를 확인합니다. 개인정보가 포함된 파일명·주소는 공통 문서에 기록하지 않습니다.

학습 성공, 시각적 품질, 웹 탐색, 이동 제한, 실측 정확성을 별도로 평가합니다. 초기 SfM 점 개수와 최종 가우시안 수를 혼동하지 않습니다. 단일 성공 사례를 전체 성공률로 표현하지 않습니다.
