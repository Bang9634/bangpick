# 0001 — 원룸 영상 3DGS 재구성

- 기록일: 2026-11-12
- 실제 실행일·실행자: 미확인
- 상태: 팀원 학습·내부 탐색 성공 보고. 웹 배포·이동 제한은 미검증.
- 근거: 사용자 설명과 공유된 환경·설정표 및 결과 화면. 원본 모델·로그는 직접 검사하지 않음.

## 환경 — 첨부 표 기준

| 항목 | 값 |
| --- | --- |
| GPU | NVIDIA RTX 3070 Ti 8GB |
| 드라이버 | 560.94 |
| OS | 미확인 |
| Python | 3.10.0, 실험 전용 .venv |
| PyTorch | 2.4.0+cu124 |
| CUDA 런타임 | 12.4 |
| CUDA Toolkit | 미확인 |
| Nerfstudio / gsplat | 1.1.5 / 1.4.0+pt24cu124 |
| COLMAP | 3.11.1 CUDA 빌드 |

이는 팀원의 실험 조합이며 프로젝트 전체의 표준 환경으로 채택된 것은 아닙니다.

## 입력과 설정 — 첨부 표 기준

- 영상 0:14~0:46에서 초당 4장 균등 추출, 960×540, 총 128장.
- 학습 112장·평가 16장. COLMAP 카메라 추정에는 128장 사용.
- COLMAP 희소 3D 점 3,662개로 초기화. 최종 가우시안 수는 미확인.
- 30,000스텝, 스텝당 이미지 1장, 시드 42, 혼합 정밀도 꺼짐.
- 처음 1/4 해상도, 3,000스텝부터 1/2, 6,000스텝부터 전체 해상도.
- 100스텝마다 정제, 15,000스텝에서 분할 종료.
- 손실: L1 0.8 + SSIM 0.2, 광고·자막 영역 마스킹.
- 렌더링: classic 모드, SH 차수 3, 학습 중 카메라 위치 보정 꺼짐.

정확한 학습 방법명·명령·config·코드 커밋은 미확인입니다. Nerfstudio/gsplat 버전만으로 Splatfacto 실행 명령을 복원하지 않습니다. 마스킹 표현은 첨부 표의 기록이며 정확한 옵션 의미를 추가 확인해야 합니다.

## 관측과 한계

사용자는 방 안을 이동하며 결과를 확인했다고 보고했습니다. 학습되지 않은 영역으로 나가면 장면이 뭉개져 보인다고 설명했습니다. 결과 화면에 보이는 품질을 전체 이동 경로의 품질로 일반화할 수 없습니다.

원본 영상·산출물 공유 위치, 모델 형식·용량, 최종 가우시안 수, 단계별 시간·최대 VRAM, 정량 평가 결과는 미확인입니다. 입력 촬영 동의·공개 범위도 모델을 공유·게시하기 전에 확인해야 합니다.

평가 16장이 카메라 추정 입력에는 포함됐다는 점을 평가 시 명시해야 합니다. 이 설정이 완전히 독립된 입력에 대한 전체 파이프라인 일반화 성능을 검증하는 것은 아닙니다. 평가 목적과 분할 기준을 별도로 정합니다.

## 다음 검증 제안

기존 산출물과 실제 설정 확보 → splat 내보내기 → 잡음·외부 영역 정리 → 품질을 확인한 이동 영역과 충돌 설정 → 자체 호스팅 뷰어 → 로딩·FPS·경계 이탈 확인.

SuperSplat·SplatTransform은 검토 후보이며 최종 선정되지 않았습니다. 이 작업은 새 학습 환경 구성부터 반복하기보다 팀원이 이미 만든 결과물의 활용 가능성을 먼저 확인하는 단계입니다.
