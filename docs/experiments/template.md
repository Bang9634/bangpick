# NNNN — 실험 제목

- 날짜: 미기록
- 작성자/실행자: 필요한 경우 팀 내 식별명 사용
- 상태: 계획 / 실행 중 / 완료 / 실패 중 선택
- 증거: 직접 실행 / 팀원 보고 중 선택

## 목적과 판정 기준

검증할 질문, 비교 조건과 성공·실패 기준을 적습니다. 실행 완료와 품질 확보를 구분합니다.

## 입력과 재현 환경

데이터 ID·촬영 동의·공유 위치·해시, 영상 구간·해상도·프레임 수·촬영 조건, 코드 커밋·설정 버전, OS·GPU·VRAM·드라이버·Python·PyTorch·CUDA 런타임/툴킷·도구 버전을 기록합니다. 모르면 미확인으로 둡니다.

해당 실험의 재현·성능 비교에 필요한 항목만 작성합니다. 개인 장비 전체 사양이나 설치 목록을 복사하지 않습니다. 비공개 자료의 실제 접근 링크·로컬 절대 경로·개인정보는 공개 문서에 넣지 않고 팀 내부 자료로 관리합니다.

## 실행 방법

작업 디렉토리, 실제 명령과 설정, 시드, 학습·평가 분할과 카메라 추정에 사용한 입력, 전처리·학습·내보내기 순서를 기록합니다. 실행하지 않은 명령은 계획으로 표시합니다.

## 결과

실제 로그·산출물 위치와 측정값을 적습니다. 소요 시간, 최대 VRAM, 카메라 등록 수/입력 수, 최종 가우시안 수, 파일 형식·용량을 필요에 따라 기록합니다. 미측정 값을 추정치로 채우지 않습니다.

웹 실험은 기기·브라우저·뷰어 버전·해상도·네트워크·캐시 조건, 최초 표시 시간·FPS 측정 경로, 이동 경계·시점 초기화·모드 전환 결과를 남깁니다. 실측 실험은 보정값과 독립 평가값을 구분합니다.

## 해석·한계·다음 검증

관측 사실과 원인 가설을 구분하고, 재현 실패나 미촬영 영역 등 한계와 다음에 확인할 조건을 적습니다.
