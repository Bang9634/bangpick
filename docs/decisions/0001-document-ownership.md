# 0001 — 공통 문서와 개인 AI 컨텍스트 분리

- 상태: 채택
- 날짜: 2026-11-12
- 근거: 사용자가 AGENTS.md의 Git 제외 해제와 개인 AI 맥락 분리를 지시한 뒤 준비 파일 구성에 동의함.

## 문제

개인 대화 요약이 공통 지침·기술 명세와 섞이면 팀원마다 다른 상태를 참고하고 불필요한 변경 충돌이 발생할 수 있습니다. 반대로 모든 지침을 제외하면 clone한 팀원에게 공통 규칙이 전달되지 않습니다.

## 검토한 선택지

모든 AI 문서를 제외하거나, 모두 Git에 포함하거나, 공통 지침과 개인 맥락을 분리하는 방법이 있습니다.

## 결정

공통 `AGENTS.md`와 `docs/`는 Git으로 공유합니다. `.ai-context/`는 개인 작업 인수인계용으로 Git에서 제외합니다. 개인 파일이 없어도 공통 개발 문서로 작업할 수 있어야 합니다.

회의·일정·담당자·토론은 Notion, 코드와 함께 바뀌는 실행법·채택된 기술 결정·실험 재현 정보는 Git에 관리합니다. 단순 채팅마다 문서를 갱신하거나 제안을 자동으로 공통 결정으로 반영하지 않습니다.

## 영향과 재검토

개인 맥락은 다른 컴퓨터로 자동 전달되지 않습니다. 팀에 필요한 내용은 검토 후 공통 문서에 옮겨야 합니다. Notion과 Git에 중복된 기준 문서가 생기면 담당 문서를 정하고 링크로 연결합니다.
