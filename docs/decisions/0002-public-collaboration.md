# 0002 — 공개 저장소와 PR 기반 협업

- 상태: 채택
- 날짜: 2026-11-12
- 근거: 사용자의 준비 파일 구성 질문 답변.

## 결정

저장소는 처음부터 공개하며 프로젝트에 필요한 정보만 포함합니다. 3인 팀의 주 담당 영역은 [팀 구성](../team.md)에 기록하며 서로 구현·검증을 지원합니다. 실명 대신 GitHub 아이디를 사용하고, 미제공 팀원은 A·B로 임시 표기합니다.

작업 브랜치에서 PR을 만들고 작성자 외 다른 팀원 최소 1명의 검토·승인 후 `main`에 병합합니다.

## 이유와 영향

변경과 검토 근거를 공유하고 담당 영역 사이의 연동 문제를 함께 확인하기 위한 기준입니다. 공개 저장소에도 개인 환경 기록·원본 데이터·접근 정보는 포함하지 않습니다.

이는 저장소를 공개로 전환하거나 GitHub 보호 규칙을 설정한 실행 기록이 아닙니다. 원격 저장소 연결 후 실제 공개 상태·권한·보호 설정을 확인해야 합니다.
